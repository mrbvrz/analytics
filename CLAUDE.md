# CLAUDE.md

Aturan kerja untuk proyek ini ada di **[`AGENTS.md`](./AGENTS.md)**. Baca berkas
itu lebih dulu — ia memuat perintah, peta berkas, aturan keras, dan definisi
selesai.

Spesifikasi visual ada di [`design-system/`](./design-system/):

- [`foundations.md`](./design-system/foundations.md) — warna, tipografi, jarak
- [`components.md`](./design-system/components.md) — komponen dan grafik
- [`content.md`](./design-system/content.md) — bahasa dan format angka

Ringkas: angka laporan selalu dari `src/data/report.json`, nilai visual selalu
dari `src/styles/tokens.css`, dan bobot huruf memakai `font-weight`, bukan
`font-variation-settings`.
